# UCS Test Analyzer — Project Overview

The UCS Test Analyzer is a Python-based tool for processing and interpreting
uniaxial compressive strength (UCS) test data.

It provides:

- Automatic UCS calculation (peak stress)
- Young’s modulus estimation from the elastic region
- Stress–strain curve plotting
- Text report generation
- Clean, modular code suitable for extension

This project is designed for rock mechanics engineers, geotechnical analysts,
and students who need a simple, transparent, and reproducible workflow for UCS
test interpretation.
